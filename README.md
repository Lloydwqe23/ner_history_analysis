# NER MODEL FOR HISTORICAL ANALYSIS
## PROBLEMS WE SOLVE
Our project uses Named Entity Recognition (NER) models to extract personal names from 15th–17th-century records in Lviv. This helps historians analyze historical interconnectedness within the city’s exceptionally diverse multinational population.
## DATASET
Our primary dataset comprises 15th–17th-century Lviv city council records provided by the Center for Digital Humanities, with 60 fully transcribed pages currently available while researchers process additional scans
